# 📊 Business Financial Intelligence Dashboard

A full-stack data analytics project covering the complete pipeline from data ingestion to ML forecasting and interactive dashboards.

## 🔧 Tech Stack
- **Python** — Pandas, NumPy, Matplotlib, Seaborn
- **SQL** — DuckDB
- **ML** — Prophet (Time-series forecasting)
- **Visualization** — Plotly, Streamlit, Power BI
- **Version Control** — Git & GitHub

## 📁 Project Structure
finance-analytics/
├── data/           # datasets
├── notebooks/      # EDA Jupyter notebooks
├── dashboard/      # Streamlit app
├── models/         # trained ML models
├── sql/            # DuckDB queries
└── README.md

## 🚀 How to Run

# Install dependencies
pip install -r requirements.txt

# Run Streamlit dashboard
streamlit run dashboard/app.py

## 📊 Features
- EDA with revenue trends, regional analysis, category breakdown
- SQL-based KPI queries using DuckDB
- 90-day sales forecasting using Facebook Prophet
- Interactive Streamlit dashboard with filters
- Power BI business report
